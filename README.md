# Home Assistant add-ons by alx2080

*Home Assistant add-ons (apps). Local vTuner: internet radio for old Pioneer receivers without the vTuner service. Documentation in Russian.*

[![Добавить репозиторий в Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Falx2080%2FvTuner_Local)

## Аддоны

- **[Local vTuner](local_vtuner)** — интернет-радио для старых ресиверов Pioneer без сервиса vTuner:
  свои станции, каталог radio-browser.info, ретрансляция HTTPS-потоков.

## Установка

1. **Настройки → Приложения → Установить приложение → ⋮ → Репозитории.**
   В старых версиях HA раздел называется «Дополнения».
2. Вставьте `https://github.com/alx2080/vTuner_Local` → **Добавить**.
3. Найдите аддон в магазине → **Установить**.

Новые версии появятся как обычное обновление аддона.
