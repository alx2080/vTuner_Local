## Add-ons

- **[Local vTuner](local_vtuner)** — internet radio for old Pioneer receivers without the vTuner service: your own stations, the radio-browser.info catalogue, relaying of HTTPS streams.

## Installation

1. **Settings → Apps → Install app → ⋮ → Repositories.** In older Home Assistant versions the section is called "Add-ons".
2. Paste `https://github.com/alx2080/vTuner_Local` → **Add**.
3. Find the add-on in the store → **Install**.

New versions appear as ordinary add-on updates.
