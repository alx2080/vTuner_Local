# Local vTuner

A replacement for the discontinued vTuner service: internet radio on old Pioneer receivers (VSX-527 and similar). See the "Documentation" tab of the add-on for details.

Заміна закритого сервісу vTuner: інтернет-радіо на старих ресиверах Pioneer (VSX-527 і подібних). Подробиці — на вкладці «Документація» додатка.
