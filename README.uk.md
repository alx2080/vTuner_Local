## Додатки

- **[Local vTuner](local_vtuner)** — інтернет-радіо для старих ресиверів Pioneer без сервісу vTuner: власні станції, каталог radio-browser.info, ретрансляція HTTPS-потоків.

## Встановлення

1. **Налаштування → Застосунки → Встановити додаток → ⋮ → Репозиторії.** У старих версіях Home Assistant розділ називається «Додатки».
2. Вставте `https://github.com/alx2080/vTuner_Local` → **Додати**.
3. Знайдіть додаток у магазині → **Встановити**.

Нові версії з'являться як звичайне оновлення додатка.
